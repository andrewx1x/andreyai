# БОТ «ЛЕНДИНГ» — ДЕМО ДОСТУП

> **Назначение:** демонстрация полного функционала ботов «МЕТРИКА» и «ДИРЕКТ» без доступа к API.
> **Формат:** Telegram-бот с фиксированными данными, видео-инструкцией и демо-отчётами.
> **Важно:** в демо нет реальных запросов к API, все данные — статические примеры.

---

## 1. ЦЕЛЬ ДЕМО-БОТА

Показать пользователю, как работает продукт до покупки:
- Быстрый обзор возможностей
- Видео настройки
- Выбор продукта: Метрика или Директ
- Демо-отчёт (как в реальном боте)
- Пример алертов
- Кнопки управления (изменить показатели/время/показать отчёт)
- Для Директа — демо-дашборд

---

## 2. ОБЩИЙ СЦЕНАРИЙ (UX FLOW)

```
/start
  ↓
Экран приветствия (что это демо, что даёт)
  ↓
Видео (инструкция + нав. выбор: Метрика / Директ)
  ↓
Выбор продукта
  ├─ Метрика → Демо-отчёт Метрики → Пример алерта → Кнопки управления
  └─ Директ  → Демо-отчёт Директа  → Пример алерта → Кнопки управления + Дашборд
```
