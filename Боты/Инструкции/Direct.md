## 1. НАЗНАЧЕНИЕ БОТА

Telegram-бот для автоматической отправки отчётов из Яндекс.Директа:
- Регулярные отчёты по рекламным кампаниям
- Сравнение с предыдущим периодом
- Алерты при резких изменениях расхода/конверсий
- Ссылка на интерактивный дашборд

**Важно:** Токен Яндекс.Директа используется **только для чтения** статистики. Бот не имеет доступа к изменению кампаний.

### 3.12 Автоматические выводы в отчёте

Бот автоматически формирует краткий вывод (1-2 предложения) на основе данных.

**Логика формирования выводов:**

| Ситуация | Вывод |
|----------|-------|
| CPA вырос >20% | `⚠️ CPA вырос на X%. Реклама стала дороже.` |
| CPA снизился >10% | `✅ CPA снизился на X%. Эффективность выросла.` |
| Конверсии упали >15% | `⚠️ Конверсии упали на X%. Проверьте кампании.` |
| Конверсии выросли >15% | `✅ Конверсии выросли на X%. Отличный результат!` |
| Расход вырос, конверсии упали | `⚠️ Расход растёт, конверсии падают. Нужна оптимизация.` |
| CTR упал >20% | `⚠️ CTR снизился. Проверьте объявления.` |

**Определение "виновника":**

```javascript
// Находим кампанию с худшим соотношением расход/конверсии
const worstCampaign = campaigns
  .filter(c => c.cost > avgCost * 0.5) // только значимые по расходу
  .sort((a, b) => (b.cost / b.conversions) - (a.cost / a.conversions))[0];

if (worstCampaign.cpa > avgCPA * 1.5) {
  insight += `Основная причина — кампания «${worstCampaign.name}»: `;
  insight += `высокий расход, мало конверсий.`;
}
```

**Рекомендации "что проверить":**

| Проблема | Рекомендация |
|----------|--------------|
| Высокий CPA в кампании | `👉 Проверьте ставки и ключи в этой кампании.` |
| Низкий CTR | `👉 Обновите тексты объявлений.` |
| Рост расхода без конверсий | `👉 Проверьте минус-слова и площадки РСЯ.` |
| Падение показов | `👉 Проверьте бюджеты и ставки.` |

**Приоритет выводов:**
1. Критичные (CPA вырос >50%, конверсии упали >30%)
2. Предупреждения (изменения 20-50%)
3. Позитивные (улучшения >15%)

## 4. API ЯНДЕКС.ДИРЕКТА

### 4.1 Базовый URL и заголовки

```http
POST https://api.direct.yandex.com/json/v5/{service}
Authorization: Bearer {TOKEN}
Client-Login: {LOGIN}
Accept-Language: ru
Content-Type: application/json
```

### 4.2 Проверка доступа (Campaigns.get)

```json
{
  "method": "get",
  "params": {
    "SelectionCriteria": {},
    "FieldNames": ["Id", "Name", "Status", "State"]
  }
}
```

**Ответ:**
```json
{
  "result": {
    "Campaigns": [
      {
        "Id": 12345678,
        "Name": "Поиск — Бренд",
        "Status": "ACCEPTED",
        "State": "ON"
      }
    ]
  }
}
```

### 4.3 Получение статистики (Reports)

```http
POST https://api.direct.yandex.com/json/v5/reports
```

**Тело запроса:**
```json
{
  "params": {
    "SelectionCriteria": {
      "DateFrom": "2026-01-20",
      "DateTo": "2026-01-26"
    },
    "FieldNames": [
      "CampaignName",
      "Impressions",
      "Clicks",
      "Ctr",
      "Cost",
      "AvgCpc",
      "Conversions",
      "CostPerConversion"
    ],
    "ReportName": "Report_20260126",
    "ReportType": "CAMPAIGN_PERFORMANCE_REPORT",
    "DateRangeType": "CUSTOM_DATE",
    "Format": "TSV",
    "IncludeVAT": "YES"
  }
}
```

**Заголовки для отчётов:**
```
processingMode: auto
returnMoneyInMicros: false
skipReportHeader: true
skipColumnHeader: false
skipReportSummary: true
```

### 4.4 Получение целей из Метрики

Для конверсий нужен связанный счётчик Метрики:

```http
GET https://api-metrika.yandex.net/management/v1/counter/{counterId}/goals
Authorization: OAuth {METRIKA_TOKEN}
```

### 6.2 Проверка алертов

```typescript
async function checkDirectAlerts(env: Env) {
  const users = await storage.getDirectUsersWithAlerts();

  for (const user of users) {
    const { current, previous } = await fetchDirectStatsForComparison(user);

    for (const rule of user.settings.alerts.rules) {
      if (wasAlertSentRecently(user, rule.id)) continue;

      const change = calculateChange(current, previous, rule.metric);

      if (shouldTriggerAlert(change, rule)) {
        const dashboardUrl = generateDashboardUrl(user);
        await sendDirectAlert(user, rule, change, dashboardUrl);
        await storage.updateAlertLastSent(user.id, rule.id);
      }
    }
  }
}
```
