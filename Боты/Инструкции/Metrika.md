## 1. НАЗНАЧЕНИЕ БОТА

Telegram-бот для автоматической отправки отчётов из Яндекс.Метрики:
- Регулярные отчёты по расписанию
- Сравнение с предыдущим периодом
- Алерты при резких изменениях
- Кастомизация показателей

**Важно:** Токен Яндекс.Метрики используется **только для чтения** статистики. Бот не имеет доступа к изменению настроек счётчика.

### 3.12 Автоматические выводы в отчёте

Бот автоматически формирует краткий вывод (1-2 предложения) на основе данных.

**Логика формирования выводов:**

| Ситуация | Вывод |
|----------|-------|
| Визиты выросли >10% | `✅ Трафик растёт — сайт привлекает больше посетителей.` |
| Визиты упали >10% | `⚠️ Трафик снизился на X%. Проверьте источники.` |
| Отказы выросли >5% | `⚠️ Отказы выросли. Проверьте скорость сайта и релевантность.` |
| Отказы снизились >5% | `✅ Отказы снизились — посетители стали активнее.` |
| Конверсия главной цели упала | `⚠️ Конверсия упала. Проверьте воронку.` |
| Конверсия главной цели выросла | `✅ Конверсия выросла — сайт работает эффективнее.` |

**Определение проблемного места:**

```javascript
// Анализируем цели для поиска проблемы
const goals = report.goals;
const mainGoal = goals.find(g => g.isMain);
const downGoals = goals.filter(g => g.change < -10);

if (mainGoal.change < -10) {
  insight += `Главная цель «${mainGoal.name}» упала на ${mainGoal.change}%. `;
}

if (downGoals.length > 1) {
  insight += `Несколько целей снизились — возможна общая проблема с сайтом.`;
} else if (downGoals.length === 1) {
  insight += `Проблема локальная — только «${downGoals[0].name}».`;
}
```

**Рекомендации "что проверить":**

| Проблема | Рекомендация |
|----------|--------------|
| Рост отказов | `👉 Проверьте скорость загрузки и мобильную версию.` |
| Падение визитов | `👉 Проверьте рекламу и SEO-позиции.` |
| Падение одной цели | `👉 Проверьте страницу с этой целью.` |
| Падение всех целей | `👉 Проверьте работу сайта и форм.` |
| Рост трафика без конверсий | `👉 Проверьте качество трафика и источники.` |

**Приоритет выводов:**
1. Сначала общая оценка (лучше/хуже периода)
2. Затем конкретная проблема (если есть)
3. Рекомендация что проверить

**Комбинированные выводы:**

| Трафик | Конверсии | Вывод |
|--------|-----------|-------|
| ↑ | ↑ | `✅ Всё отлично — трафик и конверсии растут.` |
| ↑ | ↓ | `⚠️ Трафик растёт, но конверсии падают. Проверьте качество трафика.` |
| ↓ | ↑ | `Трафик снизился, но конверсия выросла. Качество аудитории улучшилось.` |
| ↓ | ↓ | `⚠️ Трафик и конверсии падают. Требуется анализ источников и сайта.` |

## 4. API ЯНДЕКС.МЕТРИКИ

### 4.1 Проверка токена и получение счётчиков

```http
GET https://api-metrika.yandex.net/management/v1/counters
Authorization: OAuth {TOKEN}
```

**Ответ:**
```json
{
  "counters": [
    {
      "id": 12345678,
      "name": "example.com",
      "site": "example.com",
      "status": "Active"
    }
  ]
}
```

### 4.2 Получение целей счётчика

```http
GET https://api-metrika.yandex.net/management/v1/counter/{counterId}/goals
Authorization: OAuth {TOKEN}
```

**Ответ:**
```json
{
  "goals": [
    {
      "id": 123456,
      "name": "Заявка с формы",
      "type": "action"
    }
  ]
}
```

### 4.3 Получение статистики

```http
GET https://api-metrika.yandex.net/stat/v1/data
Authorization: OAuth {TOKEN}
```

**Параметры:**
| Параметр | Описание |
|----------|----------|
| ids | ID счётчика |
| metrics | Список метрик |
| date1, date2 | Период |
| dimensions | Разрезы (опционально) |

**Пример запроса:**
```
?ids=12345678
&metrics=ym:s:visits,ym:s:users,ym:s:bounceRate,ym:s:pageDepth
```

### 4.5 Обработка ошибок API

| Код | Причина | Действие |
|-----|---------|----------|
| 401 | Невалидный токен | Запросить новый токен |
| 403 | Нет доступа к счётчику | Уведомить пользователя |
| 429 | Лимит запросов | Повторить через 1 мин |
| 500+ | Ошибка API | Повторить через 5 мин |

```typescript
async function checkAlerts(env: Env) {
  const users = await storage.getUsersWithAlerts();

  for (const user of users) {
    const { current, previous } = await fetchStatsForComparison(user);

    for (const rule of user.settings.alerts.rules) {
      // Проверка cooldown (24 часа)
      if (wasAlertSentRecently(user, rule.id)) continue;

      const change = calculateChange(current, previous, rule.metric);

      if (shouldTriggerAlert(change, rule)) {
        await sendAlertMessage(user, rule, change);
        await storage.updateAlertLastSent(user.id, rule.id);
      }
    }
  }
}
```

### 9.2 Когда создаётся топик

```typescript
// При первом /start пользователя
async function handleStart(update: TelegramUpdate, env: Env) {
  const user = update.message.from;

  // Проверить, есть ли уже топик
  let adminTopic = await storage.getAdminTopic('metrika', user.id);

  if (!adminTopic) {
    // Создать топик в админской группе
    const topicId = await createForumTopic(env, {
      chatId: env.METRIKA_ADMIN_GROUP_ID,
      name: `⏳ @${user.username || 'id:' + user.id} | ${user.id} | (настройка)`,
    });

    // Отправить карточку пользователя
    await sendUserCard(env, topicId, user);

    // Сохранить
    await storage.saveAdminTopic('metrika', user.id, topicId);
  }

  // Продолжить обычную логику /start
}
```
