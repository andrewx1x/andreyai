## Правило синхронизации

При любых изменениях вносить правки **сразу в три места**:

1. Сервер (VPS) — основной деплой
2. GitHub — коммит и пуш
3. Локальная папка — обновление через git pull

## Порядок работы при изменениях

1. Внести изменения в файлы
2. Задеплоить на сервер: `scp` или редактировать напрямую через SSH
3. Закоммитить и запушить в GitHub
4. Подтянуть локально: `git pull`
